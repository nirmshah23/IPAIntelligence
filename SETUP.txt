Arcwell IPA Workspace

Run commands from this directory:
  npm install
  npm run dev
  npm run typecheck
  npm run build
  npm run preview

Structure
  src/App.tsx                 Shared navigation and URL routing
  src/index.css               Workspace layout and responsive navigation
  src/modules/intelligence/   Membership management and shared provider relations data
  src/modules/assurance/      Obligations, exceptions, calendar and reporting
  archive/                    Original applications preserved for reference

Both modules use one React runtime, dependency installation and Vite build.
Module styles use CSS @scope and require a modern browser supporting it.
Module state survives section switches. Intelligence retains its existing
localStorage behavior; assurance data remains session-only, as in the original.
The modules still use fictional demo data and do not share a backend or identity.

URLs use #/intelligence/providers or #/assurance/register, for example.
Assurance detail URLs display the session's selected obligation; the selection
is not encoded in the URL.

Validation completed in the workspace directory.
TypeScript and production build pass. Browser checks cover all navigation
links, Back and Forward, state retention, skip link, and mobile navigation.
The archive/incomplete-dependencies directory is an unused installation
artifact excluded from version control and the Tailwind source scan.

Navigation groups: Membership Management, Provider Relations, and Operational
Assurance. Groups expand and collapse to show their pages. Provider Relations
has Relations workflow (cards) and Work Plan (register and plan detail).
Summary cards filter the register; milestone and attention cards open a plan.
Examples: #/relations/relations, #/relations/workplans?filter=Attention,
#/relations/workplans?plan=WP-2003. Existing intelligence/relations links work.
